설치 순서

  1. 저장소 초대 수락

    GitHub 초대 메일에서 serashin-tech/toast-agent 초대를 수락함.

    비공개 저장소라서 초대받은 계정만 내려받을 수 있음.

  2. 저장소 내려받기

    git clone https://github.com/serashin-tech/toast-agent.git

    git이 없으면 GitHub 저장소 화면의 Code › Download ZIP으로 받아 압축을 풂.

  3. Cowork에 플러그인 설치

    Customize›Plugins›Add marketplace
    serashin-tech/toast-agent

    목록에 나온 toast-agent를 설치함.

    마켓플레이스 추가가 안 되면: 2번에서 받은 폴더 안의 plugin 폴더를 플러그인 파일로 업로드함.

  4. 작업 폴더 만들기

    토스트 작업 폴더/
├─ settings/      ← 받은 폴더의 plugin/scripts/settings-template/ 파일 4개를 복사
└─ .env           ← 받은 폴더의 .env.example을 복사해 값을 채움

    Cowork에서 이 폴더를 연결함. 나머지 폴더는 첫 실행 때 자동으로 생김.

    .env 항목넣을 값
    DATA_GO_KR_SERVICE_KEY공공데이터포털 인증키
    KOCCA_API_URL한콘진 지원사업공고 요청 주소
    SHEET_APP_URL, SHEET_APP_TOKEN5번에서 만드는 웹 앱 주소와 토큰
    SHEET_URL메일에 넣을 수집 이력 시트 주소

    .env에는 인증키가 들어 있으므로 메일이나 메신저로 보내지 않음.

  5. Google 시트 연결

    빈 시트 만들기
    →
    Apps Script에 Code.gs 붙여 넣기
    →
    스크립트 속성에 TOKEN · CEO_EMAIL
    →
    installTrigger 한 번 실행
    →
    웹 앱으로 배포
    →
    주소 · 토큰을 .env에

    자세한 순서와 설치 후 확인 방법: 저장소의 apps-script/README.md

  6. 예약 작업 2개 만들기

    매일 루틴평일 10:00
    /toast-agent:daily-routine
    2차 검토 요청 처리09:00~18:00, 30분마다
    /toast-agent:review-requests

  7. 잘 되는지 확인

    Cowork에서 "오늘 루틴 다시 돌려 줘"라고 입력함. 대표 메일함에 신규 알림 메일이 오고 시트에 행이 생기면 설치 완료.

대표가 하는 일

매일 11:00

메일 확인

오늘 새로 올라온 입찰공고, 지원사업, 외주 글을 메일로 받음. 절마다 마감이 가까운 순이고, 7일 안에 마감되는 공고에는 '마감 임박'이 붙음. 수집하지 못한 곳과 최근 설정 변경은 맨 위에 보이고, 메일의 링크로 현황판과 시트에 바로 들어감.

필요할 때

시트에서 상태 바꾸기

검토할 공고의 상태 칸을 '2차 검토 요청'으로 바꿈. 결과는 메일로 옴.

필요할 때

입찰 현황판 보기

검토 중인 공고와 상태를 한 화면에서 봄. 시트에서 바꾼 상태는 최대 30분 늦게 반영됨.

상태를 바꾸면 일어나는 일

시트에서 고른 상태다음에 일어나는 일
2차 검토 요청참가자격과 시연 필요 여부를 근거 문장과 함께 검토하고, 결과를 메일로 보냄
데모 요청Cowork에서 "데모 만들어 줘"라고 하면 시연 데모 초안을 만듦 (대표 계정에서만)
보류, 관련 없음현황판의 아래쪽으로 내려감

마감이 지난 공고는 다음 날 새벽 6시에 시트에서 빠짐. 메모나 검토 기록이 있으면 '지난 공고' 탭으로 옮겨짐.

Claude에게 말로 시키기

오늘 루틴 다시 돌려 줘→매일 루틴을 지금 실행 daily-routine
검토 요청 처리해 줘→2차 검토 요청을 바로 처리 review-requests
데모 만들어 줘→'데모 요청' 공고의 시연 데모 초안 make-demo
키워드에 홍보영상 넣어 줘→바꾸기 전후를 보여 주고 확인받은 뒤 설정 변경 change-setting
어제 바꾼 거 되돌려 줘→설정을 이전 값으로 되돌림 change-setting
주간 점검 해 줘→지난 7일의 메일 도착률과 실패를 보고 garden

알아 둘 것

  • 에이전트의 검토는 참고 자료이며, 참가 여부는 대표가 정함.
  • 근거 문장을 찾지 못한 요건은 '확인 필요'로 표시됨.
  • 시트의 메모 칸은 현황판에 나오지 않음.

관리자 설정

에이전트가 1차 필터링과 2차 검토에 쓰는 값. 대표 PC 작업 폴더의 settings/ 파일 4개에 들어 있음.

  1. 값 옆의 '고치기'로 바꾸거나 새 값을 추가
  2. 맨 아래에 만들어진 변경 요청문을 복사
  3. Cowork에 붙여 넣으면 Claude가 바꾸기 전후를 보여 주고, 확인받은 뒤 반영하고 변경 이력을 남김

현재 값은 2026-11-11 작업 폴더 기준. 이 화면에서 고친 것만으로는 실제 설정이 바뀌지 않음.
