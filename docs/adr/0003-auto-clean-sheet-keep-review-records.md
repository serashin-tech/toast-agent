# 0003. 시트의 마감 지난 행을 자동 정리하고 검토 기록은 '지난 공고'로 옮긴다

- 상태: 채택(2026-11-09, D29·D34)

## 맥락

대표는 시트에 쌓인 정보 중 마감이 지난 행을 자동으로 지우기를 원했다. 그런데 시트의 상태 칸과 대표 메모가 처리 기록의 정본(D24)이라서, 그대로 지우면 2차 검토와 데모 기록이 사라진다. 로컬 원장은 어떤 항목을 이미 보여 줬는지 판정하는 데 쓴다.

## 결정

시트에 붙인 Apps Script가 매일 시간 트리거로 마감일이 오늘보다 이전인 행을 정리한다. 상태가 '신규'가 아니거나 대표 메모가 있는 행은 '지난 공고' 탭으로 옮기고, 나머지는 지운다. 마감일이 없는 행은 등록일로부터 30일 뒤 같은 규칙을 따른다. 로컬 원장은 지우지 않고, 시트 동기화는 마감 지난 행을 다시 보내지 않는다.

## 결과

- 시트는 마감 전 공고만 담아 짧게 유지된다. 대표 PC가 꺼져 있어도 정리된다.
- 검토하지 않은 지난 공고는 시트에서 다시 찾을 수 없다(로컬 원장에는 남는다).
