# 0001. 하네스를 Claude 플러그인으로 담고 코드도 넣는다

- 상태: 채택(2026-11-09, H2·H5·H6·H14·H15)

## 맥락

무인 루틴의 지침은 사람이 Cowork에 붙여 넣는 문서였고, 금지 규칙은 그 문서 안에만 있어 지켜졌는지 확인할 수 없었다. 프로젝트 `.claude/`를 Cowork 연결 폴더에서 읽는지는 문서로 확인되지 않았고, Cowork 지원 문서는 플러그인의 훅과 서브에이전트가 Cowork에서 돈다고만 적는다.

## 결정

스킬, 에이전트, 훅, 불변 규칙, 파이썬 코드를 플러그인 하나에 담는다. 플러그인은 CLAUDE.md를 실을 수 없으므로 불변 규칙은 세션 시작 훅이 넣는다. 대표 계정에는 토스트 명의 비공개 GitHub 저장소를 마켓플레이스로 추가해 설치한다. 운영 데이터는 대표 PC 작업 폴더에 둔다.

## 결과

- 지침과 코드가 한 버전으로 함께 바뀐다. 대표는 플러그인 갱신 한 번으로 둘 다 받는다.
- 코드의 기본 경로를 작업 폴더 기준으로 바꿔야 했다(코드 위치가 PC마다 다르다).
- 확인 전 전제: 개인 계정이 비공개 저장소 마켓플레이스를 받지 못하면 플러그인 파일 업로드로 바꾼다(H14). 예약 작업에서 플러그인 안의 파이썬을 못 돌리면 코드를 작업 폴더로 되돌린다(H15).
