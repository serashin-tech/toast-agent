# 설정: 회사 프로필

제안 가능성 검토가 공고의 참가자격을 대조하는 기준입니다. **확인 상태가 '확인됨'인 값만 충족 판정에 쓰고, 그 밖의 값은 '확인필요'로 분류합니다.** 값은 대표 확인 후 고치며, 고칠 때마다 맨 아래 변경 이력에 한 줄 남깁니다.

이 파일은 새 작업 폴더를 만들 때 쓰는 빈 템플릿입니다. 실제 값은 대표 PC 작업 폴더의 `settings/company-profile.md`에만 둡니다. 판정 코드는 값 칸의 단어(보유, 미보유, 업종 이름 등)를 그대로 읽으므로, 설명은 출처 칸에 적습니다. 개인 연락처와 대표 개인 정보는 담지 않습니다.
