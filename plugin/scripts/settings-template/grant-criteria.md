# 설정: 지원사업 검색 조건

한콘진과 중소기업 지원사업 공고를 거르는 조건입니다. 관심 기관, 사업 분야, 지원사업 키워드 중 하나라도 맞으면 통과하고, 제외 키워드가 들어 있으면 항상 제외합니다. **값이 모두 비어 있으면 모든 공고가 통과합니다.** 값을 고칠 때마다 맨 아래 변경 이력에 한 줄 남깁니다.

2026-11-09 값은 검토 대상 필터 리서치 문서(2026-11-09 정리 때 지움) 3절의 초안이며 대표 확인 전입니다. 한국콘텐츠진흥원은 관심 기관에 넣지 않습니다. 넣으면 게임·음악 공고까지 모두 통과하므로, 콘진원 공고는 키워드로 거릅니다.
