# 제안 가능성 검토 입력 형식

요건 추출은 Claude가 하고, 코드는 추출된 요건을 회사 프로필 설정과 결정적으로 대조합니다. 이 문서는 코드가 받는 입력 JSON의 형식입니다.

실행: `python -m gov_agent eligibility --input 요건.json [--settings 설정폴더] [--out 결과.json]`
결과는 `docs/result-format.md`의 `eligibility[]` 항목 하나입니다. `run`이 쓰는 결과 파일의 `eligibility`에 넣는 일은 호출하는 쪽(루틴)이 합니다.

## 입력

```json
{
  "bid_id": "R26BK001",
  "unreadable_files": [{"name": "과업지시서.hwp", "url": "https://..."}],
  "requirements": [
    {
      "category": "참가자격",
      "text": "전북 소재 업체일 것",
      "kind": "소재지",
      "params": {"지역": "전북"},
      "evidence": {"quote": "공고문의 근거 문장", "location": "공고문 3쪽 2항"}
    }
  ]
}
```

- `unreadable_files`: 변환하지 못한 첨부입니다. 그대로 결과에 옮깁니다.
- `category`: 참가자격, 계약방식, 평가방식, 예산, 제출마감 등 자유 문자열입니다.
- `evidence`: `quote`와 `location`이 **둘 다** 있어야 합니다. 하나라도 비면 그 요건은 `needs_check`입니다.

## kind와 params

| kind | 대조하는 프로필 항목 | params | 충족(met) 조건 |
|---|---|---|---|
| 업종등록 | 등록한 업종(나라장터) | `업종`(문자열). 공고의 업종 제한 문구를 그대로 넣습니다(예: `비디오물제작업(3244) 또는 방송영상독립제작자(3230)`) | "또는"으로 나눈 업종 중 하나라도 프로필 값에 들어 있음. 업종코드 표기 `(숫자)`와 공백은 무시하고 비교 |
| 직접생산확인 | 직접생산확인 | 없음 | 값이 보유 계열(보유, 있음, 예 등) |
| 중소기업확인 | 중소기업 확인 | 없음 | 같음 |
| 소기업소상공인확인 | 소기업·소상공인 확인 | 없음 | 같음 |
| 벤처확인 | 벤처기업 확인 | 없음 | 같음 |
| 부설연구소 | 기업부설연구소 | 없음 | 같음 |
| 소재지 | 소재지 | `지역`(문자열) | 프로필 소재지 문자열에 지역 문자열이 들어 있음 |
| 실적 | 수행 실적 1, 2, ... | `min_count`(기본 1), `min_amount`(원, 선택) | 확인됨 행 중 조건을 만족하는 건수가 `min_count` 이상 |
| 인력 | 보유 인력(직무별 인원, 경력 연수) | `role`, `min_count` | 프로필 값을 `직무 N명, 직무 N명` 형식으로 읽어 그 직무 인원이 `min_count` 이상 |
| 기타 | 없음 | 없음 | 대조하지 않음. 항상 `needs_check` |

값이 미보유 계열(미보유, 없음, 아니오 등)이면 `unmet`입니다. 보유 계열도 미보유 계열도 아닌 값은 `needs_check`입니다.

## 판정 규칙

1. 회사 프로필이 없거나 읽지 못하면 대조하지 않습니다. 모든 요건이 `extract_only`, 종합은 `extract_only`입니다.
2. 근거(`quote`, `location`)가 없거나 `kind`가 기타(또는 모르는 값)이면 `needs_check`입니다.
3. 프로필 항목의 확인 상태가 `확인됨`이 아니거나 항목이 없거나 값이 비면 `needs_check`입니다. 확인되지 않은 값으로 `met`이나 `unmet`을 만들지 않습니다.
4. 실적은 확인 상태가 `확인됨`인 행만 충족으로 셉니다. 확인됨 행만으로 모자라도, 확인되지 않은 행이나 금액을 모르는 행까지 합치면 가능한 경우는 `needs_check`이고, 합쳐도 모자라면 `unmet`입니다. 실적 행이 하나도 없으면 `needs_check`입니다. 금액은 `5천만원`, `3억원`, `1,200만원` 같은 표기에서 읽습니다.
5. 종합: `unmet`이 하나라도 있으면 `not_recommend`, 없고 `needs_check`가 있으면 `conditional`, 모두 `met`이면 `recommend`입니다. 요건이 하나도 없으면 `conditional`입니다.
6. `disclaimer`에는 항상 "최종 판단은 대표가 합니다."가 들어갑니다.
