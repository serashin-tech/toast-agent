---
name: change-setting
description: 정부사업 에이전트의 설정(입찰공고 필터, 지원사업 검색 조건, 회사 프로필, 시연 판정 기준)을 말로 바꾸거나 되돌린다. 변경 전후를 보여 주고 한 번 확인받은 뒤, 파일 전체를 다시 쓰며 변경 이력에 한 줄을 남긴다. "키워드에 홍보영상 넣어 줘", "어제 바꾼 거 되돌려 줘" 같은 요청에 쓴다.
---

설정은 작업 폴더 `settings/`의 md 파일 네 개다(bid-filter, grant-criteria, company-profile, demo-criteria). 코드는 `## 변경 이력` 앞의 값 표만 읽는다(D11).

1. 대상 파일을 처음부터 끝까지 읽는다. 바꿀 행과 지금 값을 찾는다.
2. 변경 전과 변경 후를 표로 보여 주고 "이대로 반영할까요?"라고 한 번 묻는다. 답을 받기 전에는 고치지 않는다.
3. 반영: **Write 도구로 파일 전체를 한 번에 다시 쓴다.** 값 표를 고치고, 같은 쓰기에서 `## 변경 이력` 표 맨 아래에 한 줄(일자, 항목, 변경 전, 변경 후, 사유, 변경자)을 더한다. 변경자는 요청한 사람의 이름이다.
   - Edit를 두 번으로 나누면 훅이 첫 번째 호출을 막는다. Bash·PowerShell로 고치지 않는다.
4. 되돌리기는 이전 값을 다시 반영하는 것이다. 사유에 "되돌리기(원래 변경 일자)"를 적는다.
5. 회사 프로필의 확인 상태는 공식 기록이나 대표 확인이 있을 때만 '확인됨'으로 바꾼다. 판정 코드는 값 칸의 단어를 그대로 읽으므로 설명은 출처 칸에 적는다.
6. 끝나면 다음 날 신규 알림 메일과 사업 현황판에서 결과를 확인하라고(사후 검토) 한 줄로 알린다.
