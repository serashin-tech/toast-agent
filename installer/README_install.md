# 토스트 에이전트 설치 안내 (대표님 PC)

`install.bat`을 실행하면 대표님 PC에 **작업 폴더**(기본 `D:\toast-work`)가 만들어집니다. 이 작업 폴더를 Cowork에 연결하면, 매일 수집 결과와 검토 기록이 그 안에 쌓입니다.

- 소요 시간: 60분 내외
- 순서대로 진행하고, 끝나면 맨 아래 "회신" 항목을 sera.shin@codepresso.kr로 보내 주세요.
- 인증키, 토큰, 메일 주소는 메일·카톡으로 보내지 말고 이 PC에만 입력합니다.
- `install.bat`은 여러 번 실행해도 됩니다. 이미 있는 설정과 작업 결과는 지우지 않고, 비어 있던 값만 채웁니다.

## 0. 설치 파일 받기

- [ ] GitHub 저장소 `toast-agent` 화면에서 Code > Download ZIP을 누르고, 받은 파일의 압축을 풉니다.
- [ ] 압축을 푼 폴더 안의 `installer` 폴더에 이 안내서와 `install.bat`이 있습니다.

## 1. 공공데이터포털 인증키 받기 (승인 전이어도 다음 단계 진행 가능)

- [ ] https://www.data.go.kr 가입(본인인증)
- [ ] 아래 3개 페이지에서 각각 "활용신청"(서비스키 종류는 세 건 모두 같은 것으로)
  - https://www.data.go.kr/data/15129394/openapi.do (조달청 입찰공고)
  - https://www.data.go.kr/data/15157820/openapi.do (중기부 지원사업)
  - https://www.data.go.kr/data/15134251/openapi.do (한콘진 지원사업)
- [ ] 활용목적 상세 설명에 넣을 문구:
  > 토스트 애니메이션 스튜디오 내부 업무용입니다. 회사 사업 분야에 맞는 입찰공고와 정부 지원사업 공고를 하루 한 번 조회해 대표에게 알림 메일과 내부 검토 목록으로 제공합니다. 조회한 데이터는 외부에 재배포하지 않습니다.
- [ ] 마이페이지 > 데이터활용 > Open API > 활용신청 현황에서 "승인"을 확인하고, 일반 인증키를 복사해 둡니다.
- [ ] 한콘진(15134251) 신청 상세 화면에서 요청 주소(End Point)를 복사해 둡니다. 보이지 않으면 회신 때 "못 찾음"으로 알려 주세요.

## 2. Google 시트 준비 (토스트 명의 Google 계정)

- [ ] 빈 Google 시트를 만듭니다.
- [ ] 확장 프로그램 > Apps Script를 열고, 압축을 푼 폴더의 `apps-script\Code.gs` 내용을 모두 붙여 넣고 저장합니다.
- [ ] 편집기 위쪽에서 함수 `installTrigger`를 골라 실행하고, 뜨는 권한 창에서 허용합니다.
- [ ] Apps Script 창은 열어 둔 채로 3단계로 갑니다.

## 3. install.bat 실행 (작업 폴더 만들기)

- [ ] `install.bat`을 더블클릭합니다. "Windows의 PC 보호" 창이 뜨면 "추가 정보" > "실행"을 누릅니다.
- [ ] 작업 폴더 위치를 묻으면 그냥 Enter를 누릅니다(기본 `D:\toast-work`). 이후 위치를 옮기지 않습니다.
- [ ] 시트 토큰이 클립보드에 복사되었다고 나오면, Apps Script > 프로젝트 설정 > 스크립트 속성에 두 값을 넣습니다.
  - `TOKEN`: Ctrl+V로 붙여 넣기
  - `CEO_EMAIL`: 알림을 받을 대표님 메일 주소
- [ ] Apps Script에서 배포 > 새 배포 > 유형 "웹 앱", 실행 사용자 "나", 액세스 권한 "모든 사용자"로 배포합니다.
- [ ] install 창으로 돌아와 Enter를 누르고, 묻는 순서대로 붙여 넣습니다: 웹 앱 주소 → 시트 주소 → 공공데이터포털 인증키 → 한콘진 요청 주소. 아직 없는 값은 Enter로 넘깁니다.
- [ ] 끝나면 작업 폴더가 열립니다. 넘긴 값은 받는 대로 `install.bat`을 다시 실행해 채웁니다.

## 4. Claude 데스크톱 설정

- [ ] Claude 데스크톱 앱을 설치하고 대표님 계정으로 로그인합니다.
- [ ] 설정 > Capabilities > 코드 실행에서 **Allow network egress**를 켜고, Domain allowlist를 "Package managers"로 둔 뒤 아래 도메인을 한 줄씩 추가합니다. (Team 플랜이면 조직 관리자가 추가해야 합니다.)

```
apis.data.go.kr
cglink.com
script.google.com
script.googleusercontent.com
www.g2b.go.kr
www.bizinfo.go.kr
www.kocca.kr
```

- [ ] 한콘진 요청 주소를 받았다면 그 주소의 도메인(예: `https://` 뒤부터 첫 `/` 앞까지)도 추가합니다.

## 5. 플러그인 설치와 폴더 연결

- [ ] Cowork > Customize > Plugins > Add marketplace에 `<대표님 GitHub 아이디>/toast-agent`를 넣고, `toast-agent` 플러그인을 설치합니다.
- [ ] Cowork에서 3단계에서 만든 작업 폴더(기본 `D:\toast-work`)를 연결합니다.
- [ ] Cowork 대화창에 다음을 입력합니다: `markitdown과 kordoc이 쓸 수 있는지 확인하고, 없으면 설치해줘`

## 6. 예약 작업 만들기

- [ ] 예약 작업 1: 평일 10:00, 내용 `/toast-agent:daily-routine`, 작업 폴더는 `D:\toast-work`
- [ ] 예약 작업 2: 평일 09:00~18:00 30분마다, 내용 `/toast-agent:review-requests`, 작업 폴더는 `D:\toast-work`
- [ ] 두 작업 모두 **지금 실행**을 한 번 누르고, 권한 확인 창이 뜨면 도구마다 **항상 허용**을 고릅니다. 이 단계를 건너뛰면 다음 날부터 자동 실행이 멈춥니다.

## 7. PC 설정

- [ ] Windows 설정 > 전원에서 절전을 "안 함"으로 둡니다. 노트북이면 덮개를 닫지 않습니다.
- [ ] Claude 데스크톱이 PC를 켤 때 자동으로 실행되게 둡니다.
- [ ] 평일 10:00~18:00에는 PC와 Claude 데스크톱을 켜 둡니다. 꺼진 날은 그날 수집이 '미실행'으로 남습니다.

## 8. 확인과 회신

- [ ] 대표님 메일함에 "[토스트]" 알림 메일이 왔는지 확인합니다.
- [ ] Google 시트에 '수집 이력' 탭과 행이 생겼는지 확인합니다.
- [ ] sera.shin@codepresso.kr로 회신합니다.
  - 설치 완료 여부
  - "지금 실행" 결과 화면(실패 메시지가 있으면 캡처)
  - 한콘진 요청 주소(비밀값이 아니므로 보내셔도 됩니다)

## 설치 후 작업 폴더에 쌓이는 것

| 폴더·파일 | 내용 | 다루는 방법 |
|---|---|---|
| `settings\` | 입찰공고 필터, 지원사업 기준, 회사 프로필, 시연 기준 | 직접 고치지 말고 Cowork에 "설정 바꿔줘"라고 말합니다 |
| `.env` | 인증키·시트 비밀값 | 다른 사람에게 보내지 않습니다 |
| `results\` | 날짜별 수집 결과 | 지우지 않습니다 |
| `reports\` | 알림 메일 본문, 사업 현황판 | 지우지 않습니다 |
| `runs\` | 실행 기록 | 지우지 않습니다 |
| `state\` | 이미 알린 공고 목록 | 지우면 같은 공고를 다시 알립니다 |
| `drafts\<공고번호>\` | 2차 검토 첨부와 판정, 데모 산출물 | 공고별 처리 기록의 정본입니다 |
