# 01: 보고서 HTML 기능을 신규 알림 메일로 옮기기 (D35)

**What to build:** 신규 알림 메일의 각 절이 마감이 가까운 순으로 정렬되고, 마감 7일 이내 항목에 '마감 임박'이 붙으며, 최근 7일 안의 설정 변경이 메일 위쪽에 한 줄(전날 대비 포함·제외 건수 포함)로 보인다. `build`는 더 이상 보고서 HTML을 만들지 않고 실행 기록만 남긴다.

**Blocked by:** 없음

**Status:** resolved (2026-11-11)

**명세:** `.scratch/daily-report/spec.md`의 '신규 알림 메일', '없애는 것', Testing Decisions의 메일·`build` 항목

- [x] 메일 절 안 정렬: 마감일 오름차순, 마감 없는 항목은 뒤
- [x] '마감 임박' 표시: 마감까지 0~7일
- [x] `mail`에 설정 폴더 인자를 더해 최근 설정 변경 한 줄과 전날 대비 건수(오늘·전날 모두 성공한 소스만)
- [x] `build`가 `report-<날짜>.html`을 쓰지 않음. 실행 기록 줄은 그대로
- [x] 보고서 전용 코드(오늘 볼 3건, 보기 위젯, 카드·제안 가능성 검토 표시) 삭제. 메일·현황판이 쓰는 도우미는 남김
- [x] `daily-routine` 스킬의 `mail` 명령에 `--settings settings` 추가, 2단계 설명을 '실행 기록 시작'으로 유지
- [x] 시험: 위 동작을 메일 출력으로 확인(TDD), 기존 보고서 HTML 시험은 지우거나 메일 시험으로 옮김
- [x] `plugin.json` 버전 올림, 설명서의 루틴 흐름도가 바뀐 메일 내용과 맞는지 확인
