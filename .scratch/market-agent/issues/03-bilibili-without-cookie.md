# Bilibili를 쿠키 없이 한국 IP에서 수집할 수 있는지 시험

## 질문

로그인 쿠키 없이 한국 IP에서 Bilibili 검색, 영상 정보, 자막 수집이 되는가?

## 확인 항목

- [ ] 중국어 키워드 1개로 최근 7일 영상을 검색한다
- [ ] 제목·채널·게시일·조회수·링크가 나오는지 확인한다
- [ ] 자막(CC 또는 AI 자막) 수집이 되는지 확인한다
- [ ] 로그인 또는 쿠키를 요구하는 오류가 나오면 그 메시지를 기록한다

## 완료 기준

쿠키 없이 검색과 영상 정보가 나오지 않으면 Bilibili를 P1로 내린다(§6-3 순서 1). 대표 계정 쿠키를 저장하는 방식은 쓰지 않는다.
