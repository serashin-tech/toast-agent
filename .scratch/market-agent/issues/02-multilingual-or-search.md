# 4개 언어의 이번 주 필터 검색과 키워드 OR 묶음 검색 시험

## 질문

언어별로 키워드 여러 개를 OR(`|`)로 묶어 yt-dlp 이번 주 필터 검색 1회로 받을 수 있는가? 묶었을 때 결과가 한쪽 키워드에 쏠리지 않는가?

## 확인 항목

- [ ] 한국어·영어·일본어·중국어 키워드 각 1개로 이번 주 필터 검색이 되는지, 결과 건수와 소요 시간을 기록한다
- [ ] 언어별로 키워드 3개를 OR로 묶어 1회 검색하고, 결과 30건이 각 키워드에 얼마나 나뉘는지 센다(제목·설명문에 키워드가 들어 있는지로 판정)
- [ ] 묶음 검색이 되지 않거나 한 키워드에 80% 넘게 쏠리면, 매일 언어별 2개 키워드씩 순환하는 방식으로 정한다
- [ ] 상위 3건을 Agent Reach `youtube read`로 조회해 게시일이 이번 주인지 확인한다
- [ ] 시험 전체의 YouTube 요청 수를 20회 안쪽으로 유지하고, 429가 나면 즉시 멈춘다

## 완료 기준

언어별 결과표와 묶음/순환 중 어느 방식을 쓸지 Answer에 남긴다. 결과가 나쁜 언어는 PRD §6-3 절단 순서 1번(일본어·중국어 제외)의 판단 근거로 쓴다.

## Comments

## Answer (2026-11-05, 코드프레소 PC)

YouTube 요청은 12회(검색 8회, 게시일 확인 4회)였고, 429는 나지 않았다. 검색 1회에 7~20초가 걸렸다.
키워드 판정은 각 키워드의 첫 단어가 제목·설명문에 들어 있는지로 했다(대략적인 판정).

| 언어 | 단일 검색(30건) | OR 3개 묶음(30건): 1번 / 2번 / 3번 / 없음 |
|---|---|---|
| 한국어 | AI 애니메이션 28건 | 26 / 8 / 0 / 4 (1번 87%) |
| 영어 | AI animation 29건 | 21 / 6 / 0 / 5 (1번 70%) |
| 일본어 | AIアニメ 20건, 없음 10건 | 21 / 2 / 0 / 7 (1번 70%) |
| 중국어 | AI动画 13건, 없음 17건 | 3 / 0 / 0 / 27 (대부분 무관) |

- OR 묶음 검색은 동작하지만 1번 키워드에 쏠린다. 한국어는 기준(80%)을 넘었다. 3번 키워드(홀로그램)는 모든 언어에서 0건이었다.
- 중국어 검색은 결과 대부분이 키워드와 무관했다(드라마, 축구 패러디 등). YouTube의 중국어 콘텐츠 자체가 적은 영향으로 보인다.
- **조회수 순 상위가 제작 기법과 무관한 경우가 많다.** 예: AI 패러디 영상(62만), 게임 1주년 MV(12만), "$7M 애니메이션 시리즈"(1,600만), 게임 팬아트, 축구 선수 패러디. 조회수만으로 고르면 오락 영상이 보고서를 채운다.
- 게시일 확인 표본 4건은 10/31~11/2였다. "이번 주" 필터는 최근 7일로 동작한다.
- Agent Reach `youtube read`는 앞선 자막 429 때문에 Agent Reach 자체의 쿨다운(약 1시간)에 걸려 있었다. 이 쿨다운은 채널(YouTube) 단위라서, 한 동작에서 429가 나면 read까지 함께 멈춘다. 게시일은 yt-dlp를 직접 호출해 확인했다.

결정이 필요한 사항: 관련도 판정 단계 추가 여부, 묶음/순환 선택, 중국어 유지 여부.

### 결론 (2026-11-05, 상위 PRD V1.7에 반영)
- 관련도 판정 단계를 넣는다: 후보의 제목·설명문·태그를 Claude가 읽고 제작 기법·도구·연출 관련 여부와 근거 한 줄을 남긴 뒤, 관련 있는 후보만 조회수 순으로 정렬한다.
- OR 묶음 검색은 쓰지 않고, 매일 언어별 키워드 2개씩 순환해 단독 검색한다(검색 6회 + 게시일 확인 최대 9회).
- 중국어는 뺀다. 언어는 한국어·영어·일본어, 하루 최대 9건.
- 429를 받으면 그날 수집은 실패로 처리하고 재시도하지 않는다(Agent Reach 쿨다운 약 1시간).
